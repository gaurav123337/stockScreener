# stockScreener — Architecture Guide

> **Mandatory reading before any code change.**
> The `architecture-rules` skill enforces these rules automatically.

## Layer Structure

```
┌──────────────────────────────────────────────────┐
│  PRESENTATION  │  api.py (FastAPI)  main.py (CLI)│
│  ── Thin handlers, delegate to services ──       │
├──────────────────────────────────────────────────┤
│  APPLICATION   │  screener/services/              │
│  ── Business logic, orchestration ──             │
├──────────────────────────────────────────────────┤
│  DOMAIN (CORE) │  screener/core/                  │
│  ── Models, interfaces, config, DI, plugins ──   │
├──────────────────────────────────────────────────┤
│  INFRASTRUCTURE│  screener/infrastructure/         │
│  ── Yahoo Finance, CSV persistence ──            │
└──────────────────────────────────────────────────┘
```

## Dependency Rule

```
Presentation → Application → Domain ← Infrastructure
```

Dependencies must **always point inward**. Outer layers depend on inner layers, never the reverse.

## Quick Rules

| # | Rule | Status |
|---|------|--------|
| R1 | Presentation must NOT import infrastructure | ✅ Clean |
| R2 | Domain must NOT import services/infrastructure | ✅ Clean |
| R3 | Services must NOT import presentation | ✅ Clean |
| R4 | Infrastructure must implement core interfaces | ✅ Clean |
| R5 | No direct `Service()` in presentation | ✅ Clean |
| R6 | No hardcoded values in services | ✅ Clean |
| R7 | New features via plugin registry, not core edits | ✅ Clean |
| R8 | Handlers must be thin (<20 lines logic) | ✅ Clean |

## How to Add Features

### New Filter
1. Create class extending `FilterStrategy` in `screener/services/filter_service.py`
2. Register: `filter_service.register_filter(MyFilter())`

### New Scorer
1. Create class extending `ScoringStrategy`
2. Register: `scoring_engine.register_scorer(MyScorer())`

### New Data Provider
1. Implement `MarketDataProvider` in `screener/infrastructure/data/`
2. Register in `bootstrap.py`: `container.register(MarketDataProvider, MyProvider)`

### New API Endpoint
1. Add method to appropriate service
2. Add thin handler in `api.py` using `get_service()`

### New CLI Command
1. Add method to appropriate service
2. Add thin handler in `main.py` using `get_service()`
